# Multi-Task Management API

A simple RESTful API for managing multiple tasks using Node.js, Express.js, and MongoDB.

## Features

- User authentication
- JWT-based authentication
- Create tasks
- Get tasks
- Update tasks
- Delete tasks
- User-specific task ownership
- Input validation
- Error handling

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
